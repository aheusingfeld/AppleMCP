# LocalMCP 1.0.3 (23) — preparation

Scope: integrate PR #34, address the explicit missing-body contract in #35, and remove the timing race identified by PR #34's CI failure. Preserve the current Store submission and all permissions, file bounds and read-only operations.

Acceptance:
- Absolute year/month/day/ISO timestamp filters reject invalid values, honor Gregorian dates and explicit/local time zones, and include complete named periods.
- The same date interpretation drives filtering, returned dates and sorting before pagination. Document the inherited heuristic for ambiguous Mail epochs.
- Mail reads and requested search bodies expose available/empty/unavailable states and reasons. Missing local files do not imply an empty message. Body searches disclose incomplete coverage and non-exact totals.
- Synthetic SQLite/emlx fixtures exercise missing, empty, malformed and normal bodies, mixed-epoch ordering, invalid timestamps, DST and non-Gregorian user calendars.
- Cancellation test waits for observable child start/release rather than racing fixed sleeps; no production deadline is relaxed.
- Update tool descriptions, README and release notes. Prepare version 1.0.3 build 23; do not upload or replace the pending Store build.

Files: MailProvider.swift; ToolCatalog.swift; imported ToolArgumentPolicy.swift and argument-validation tests; MailProviderSearchSemanticsTests.swift; SpeechPrivacyPolicyTests.swift; README.md; CHANGELOG.md; version constants/plists and xcode/project.yml; this release plan and evidence; xcode/README.md to replace stale version/distribution instructions.

Verification: targeted Mail/argument tests, full swift test, CI's ThreadSanitizer selection, release build, documentation and bundle metadata checks, independent diff review/security audit, GitHub CI.

Decision: an AppleScript fallback is not part of this release. The Store sandbox has no Mail AppleEvents exception; introducing one needs a separate entitlement/consent design and real Exchange/Store validation. #35's minimum reliable status and documentation solution is implemented instead.

Release gates remaining after source preparation: real Exchange-account acceptance; native application smoke test for the candidate; signed archive/upload and Apple review. No claim that missing Exchange body text has become readable.

Change log: the existing mixed subject/body test now expects a lower-bound total when other candidates have unavailable bodies; its matching assertion is unchanged. Added a sub-millisecond period-edge regression after reproducing a dropped last-in-period message. Short-form bounds use an exclusive next-period boundary while preserving millisecond display metadata.

Independent review fix round: a synthetic 131-part MIME message reproduced false complete coverage when the multipart part cap was reached. Propagate part/depth/discarded-text limits into body truncation and search totals. Also preserve case-sensitive MIME boundary values; an exact-preview regression reproduced boundary syntax leaking into extracted text. Both fixes stay in MailProvider and its existing semantics tests.
