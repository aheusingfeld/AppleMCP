# LocalMCP 1.0.3 (23) — next-update preparation

Prepared 3 October 2026. Source candidate only: no TestFlight upload, Store submission or
replacement of the installed app. The existing 1.0.2 (22) submission is unaffected.

## Release notes — Deutsch

- E-Mails gezielt nach Jahr, Monat, Tag oder einem genauen Zeitraum durchsuchen.
- Verlässlichere zeitliche Sortierung, auch bei unterschiedlichen Zeitformaten im Mail-Index.
- Klare Kennzeichnung fehlender oder gekürzter Nachrichtentexte, insbesondere bei Exchange.
  Unvollständige Textsuchen werden ausdrücklich ausgewiesen.
- Verbesserte Verarbeitung mehrteiliger E-Mails und zusätzliche Stabilitätsprüfungen.

## Release notes — English

- Search email by year, month, day or a precise date range.
- More reliable chronological ordering across mixed timestamp formats in the Mail index.
- Clear status for unavailable or truncated message text, including Exchange accounts.
  Incomplete body searches are explicitly identified.
- Improved multipart email handling and additional stability checks.

## Scope and traceability

PR #39 integrates the original PR #34 commits, then hardens validation, period boundaries
and sorting. Issue #35 is addressed through its minimum status/documentation solution:
`body_status`, `body_reason`, `body_source`, `body_truncated` and search coverage metadata.
Unavailable Exchange text has **not** become readable. A Mail AppleScript fallback would need
its own sandbox entitlement/consent design and real-account testing; none is added here.

The inherited Mail epoch heuristic remains documented in the README. Older/future ambiguous
source dates cannot be classified with certainty from the numeric column alone.
